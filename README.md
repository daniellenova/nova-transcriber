# Nova Transcriber

Проект находится в разработке. Описанные ниже возможности MVP запланированы и пока не заявляются как реализованные.

## Назначение

Nova Transcriber — локальный сервис автоматической транскрибации аудио- и видеозаписей с сохранением результатов и истории.

## Ключевая идея

Простой, автономный и расширяемый сервис с логическим разделением способов взаимодействия, распознавания речи, бизнес-логики и хранилища. Модульность без преждевременной микросервисной архитектуры.

## Технологический стек MVP

- Python и uv.
- faster-whisper и Whisper Large-v3.
- CPU, INT8.
- Docker Compose.
- PostgreSQL.
- Telegram, aiogram и локальный Telegram Bot API.

## Архитектурные принципы

- Telegram — один из возможных интерфейсов; Core от него не зависит.
- ASR — отдельный заменяемый модуль; Core не зависит от конкретного движка.
- PostgreSQL хранит метаданные и полные тексты транскрибаций.
- Один экземпляр приложения без распределённой инфраструктуры.
- Перенос на другой компьютер через Docker Compose.

## Планируемая функциональность MVP

1. Получение аудио или видео через Telegram.
2. Распознавание русской речи.
3. Сохранение транскрибации и метаданных в PostgreSQL.
4. Возврат полного текста в TXT.
5. Получение предыдущих результатов через `/history`.
6. Доступ только разрешённому Telegram-пользователю.

## Направление развития

Веб-интерфейс, другие ASR-модели, удалённые вычислители и дополнительные способы обработки текста — возможные направления развития, а не функции текущего MVP.

## Запуск через Docker

Положите аудиофайл в `./data` и из корня проекта выполните (требуется Docker Compose):

```sh
docker compose run --build --rm transcriber "/data/Запись.m4a"
```

TXT появится в `./data`; кэш весов модели хранится в `./models` и сохраняется при пересоздании контейнера. Python и faster-whisper в Windows устанавливать не требуется.
